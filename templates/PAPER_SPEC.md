# 国赛论文格式与写作规范

本文件是项目的可执行约束，不替代当年官方通知。2026 档案参考：

<https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html>

## 论文结构

```text
摘要（含关键词）
1 问题重述
2 问题分析
3 模型假设
4 符号说明
5 模型建立与求解
6 模型评价
参考文献
附录
```

正文应围绕题目小问组织。不要为了凑结构声称没有实现的方法；每一个结论都要能追溯到数据、公式、代码或明确的假设。

## 页面与字体

| 元素 | 规则 |
|:---|:---|
| 纸张 | A4 |
| 页边距 | 上下左右不小于 2.5 cm |
| 标题 | 黑体、居中、加粗；英文使用 Times New Roman |
| 一级标题 | 黑体、居中、加粗 |
| 二级/三级标题 | 黑体、左对齐、加粗 |
| 正文 | 宋体 12 pt，英文 Times New Roman，两端对齐，首行缩进 |
| 图题/表题 | 宋体 10.5 pt，加粗，居中 |
| 页码 | 页脚居中，使用阿拉伯数字 |
| 目录 | 默认不生成 |

具体字号与行距由 `templates/reference.docx` 控制。不要在 Markdown 中靠大量空行或手工分页“修版”。

## 摘要

- 摘要必须能独立说明背景、方法、主要结果和模型评价。
- 按“针对问题一、针对问题二……”组织，方法名称可加粗，数字不要为了突出而加粗。
- 关键词使用空格分隔，通常 4-6 个。
- 目标是控制在摘要专用页内；审计器对过长摘要只给出风险提示。

## 图表

- 表题放表格上方，格式：`**表1 标题**`。
- 图题放图片下方，格式：`![图1 标题](figures/xxx.png)`。
- 图号、表号分开编号，从 1 开始连续。
- 图片文件不嵌入标题，标题统一由 Markdown 管理。
- 表格优先不超过 6 列；宽表拆分为多个有明确主题的窄表。
- 表内避免 LaTeX 公式，使用 `R²`、`ε`、`γ`、`±` 等 Unicode；正文段落可使用 LaTeX。
- 三线表由 `reference.docx` 的 `Table` 样式定义，后处理只负责 autofit 和验证。

## 公式

```markdown
行内公式：$R^2$、$\beta$、$x_i$

显示公式：
$$
f(x) = ax+b \qquad (1)
$$
```

避免 `\tag{}`、`\left`、`\right`、`\bigl`、`\bigr`、自定义宏和空公式块，以减少 Word 公式转换风险。

## 参考文献

- 每条文献必须真实、可检索、与论文内容相关。
- 正文引用使用 `[1]`、`[2]` 等编号，且参考文献编号按正文首次出现顺序排列。
- 不能把 AI 生成的“看起来合理”的作者、期刊、年份、页码直接写进论文。
- 用 `web_search` 找线索、`web_fetch` 打开原文核验官方资料和论文；搜索摘要、二手转述和模型记忆都不算证据。
- 查不到的条目删除或标记“待查”，不得由 AI 生成作者、期刊、年份、页码或 DOI。

## 附录与支撑材料

- 附录 A 列出实际使用的代码、数据和支撑文件。
- 附录 B 说明核心代码结构；如需图片化代码，用 `gen_code_images.py` 生成。
- 支撑材料使用 `package_support.py` 生成 ZIP，最终文件类型和大小以当年官方提交通知为准。

- [ ] 所有数字可由代码复现

- [ ] 参数边界、异常值和模型局限已说明

- [ ] 图表编号连续且正文全部引用
- [ ] 参考文献全部可核实且正文有引用
- [ ] 论文无目录、身份信息和训练痕迹
